# 로컬 변경 정리 — 2026-10-28

사용자 요청에 따라 미커밋 변경을 검토하고, 재사용할 연구 기능을 남겼다.
판단 기준은 평가의 정확성, 통제 비교의 재현성, 실측 근거 보존과 공용 서버 운영이다.
발표 그림을 만들기 위한 수치 대입·포장 및 완료된 단발 실행기는 활성 코드에서 제외했다.

실측 분석기는 중복/역행 step과 비유한 지표를 거부하고, 각 모델의 모든 시드가 관측된 step만
평균낸다. 원래 기록에 없는 값을 만들거나 별도 replay를 자동 병합하지 않는다.
단일 시드는 n=1로 표시하며 min–max는 신뢰구간이 아니다. 예산 완료 여부를 추정하지 않고
관측된 최고점만 보고한다. 입력 해시와 실제 시드 수를 결과에 기록한다.

작업 전 미커밋 파일 전체는 로컬 전용 `results/experiments/local_cleanup_20261028/before/`에
백업했다. 제외된 코드도 여기서 복구할 수 있다. `manifest.json`에 원래 파일 해시와 보존 대상
실험 파일 해시가 있다. 이 보관소는 Git에 포함되지 않는다.

기존 실험 원자료, 체크포인트, 발표 그림과 frozen 소스는 삭제·재생성하지 않았다.
이전 발표 그림을 재현할 때는 보관된 당시 코드와 데이터의 조합을 사용한다.
일회성 파일을 보관소로 옮기는 과정에서 측정값을 변경하지 않았다.

검증: CPU 단위 테스트 94개 통과, 유지한 셸 실행기 문법 검사 통과.
원자료·그림·frozen 소스 528개 파일과 이동한 PDF의 SHA-256이 작업 전과 일치했다.
범용 분석기로 기존 678개 관측치를 별도 임시 폴더에서 읽어, 기존 시드 평균 궤적의
관측 최고 step과 최종 지표가 재현됨을 확인했다. 새 GPU 학습·평가는 실행하지 않았다.
