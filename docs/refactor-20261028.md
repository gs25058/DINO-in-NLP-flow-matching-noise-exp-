# 현재 실험 브랜치 구조 정리

대상 브랜치: `exp/coviso-component-relaxation`. 변경 전 기준: `e1d2ea33339e8040fbbcdfd97d8b984df51779d2`.
범위는 공동 Optuna 실험의 학습·평가·분석이다. 다른 브랜치는 수정하지 않는다.

## 보존 범위와 구조

`run_coviso_optuna.py → Trainer.training_step → DINOObjective → optimize → dev 평가/저장`이
학습 경로다. 완주 trial의 상위 3개 추가 시드 검증과 후보 동결 후 STS7도 유지한다.
`analyze_optuna.py`가 실제 로그·study의 시드별 평균/SD, 손실/gradient·표현 기하, 최종 판정을 집계한다.

- `model.py`는 masked mean+L2와 DINO head, 한 번의 teacher EMA를 담당한다.
- `augment.py`는 clean teacher와 독립 flow-noise student 뷰만 생성한다.
- `loss.py`에 함께 읽어야 하는 DINO·covariance·성분 결합·gradient 진단을 모았다.
- `train.py`는 데이터/config 준비, 계산, optimizer/EMA, 진단, 평가·저장 메서드를 분리했다.
- `provenance.py`가 고정 소스와 실행/데이터/초기값 증거를 관리한다. 중단된 매트릭스 실행기에 의존하지 않는다.
- 모델·공분산 결과에는 이름 있는 dataclass를 쓴다. 인덱스와 가변 길이 tuple을 제거했다.
- 평가의 pooling은 mean+L2로 고정하고, head 재호출을 줄였다. 세 표현 공간 진단은 유지한다.

소스와 실행 Python은 5,757줄에서 2,507줄로 줄었다(정리 직후 기준; 포맷 변화 포함).
파일 수를 목표로 나누지 않았으며, 학습 함수 하나에 진단과 과거 실험 분기를 남겨 두지 않았다.

## 삭제 근거

실제 명령·config·진행 중 study를 확인한 뒤, 63개 기존 파일을 삭제했다.
새 `legacy`/`old`/`archive` 폴더나 호환 래퍼는 만들지 않았다.

- 현재 목적함수에 없는 velocity head/loss, KoLeo, center/embedding uniform push와 consistency 증강.
- 사용하지 않는 CLS/first-last·평가 후처리·길이 probing과 SimCSE 모델/학습/구형 checkpoint 지원.
- 과거 전용 dense 진단·collapse guard·다중 탐색기·후처리 재채점·발표 그림과 overlay 도구.
- 중단된 고정 매트릭스와 조건부 감쇠 실행기/config, R1–R19 과거 run 설정과 그 전용 설명/테스트.
- 활성 설정에 없는 분기용 키, 중복된 scalar 가중치 상속과 현재 경로가 쓰지 않는 API.
- 비활성 W&B와 삭제 도구의 의존성. lock의 패키지는 105개에서 87개가 됐다.

과거 구현·기록은 Git 이력과 해당 브랜치에 있다. 데이터·checkpoint·실행 결과와
진행 중 campaign의 고정 소스는 삭제하거나 수정하지 않았다.

## 참고 코드 검토

최신 확인 버전은 [5228380](https://github.com/don-gik/SSL-based-Embedding/commit/5228380)이다.
현재 OT/Grokfast 구현을 이식하지 않았다.
[5f48385](https://github.com/don-gik/SSL-based-Embedding/commit/5f483857c7e7056ad860d9dbfea0a7cfb51b8d84)의
`DinoNoiseSystem.training_step`에서 인코딩→pooling→head→loss가 바로 보이는 구조와
EMA·평가 책임 분리를 참고했다.
[13578db](https://github.com/don-gik/SSL-based-Embedding/commit/13578dbcbeb53ee5d0c3b92665d8a277ebc76530)는
head의 출력 가중치와 word embedding을 묶은 뒤 backbone/head EMA 루프에서 같은 파라미터를
두 번 갱신한다. 이 동작과 별도 covariance/variance 수식은 복사하지 않았다.
우리 EMA는 모델의 중복 제거된 `parameters()`를 한 번 순회하며, 공유 가중치에 대한 테스트도 남겼다.
Lightning은 도입하지 않았다.

## 수치 보존과 검증

수정 전 **114 tests passed**. 삭제된 기능만을 위한 테스트를 함께 제거하고,
유지한 수식·gradient·EMA·sampling·평가를 검증하는 **59 tests passed**를 확인했다.
테스트 수의 감소를 성공 기준으로 사용하지 않았다.

변경 전 실제 코드를 `/tmp`의 독립 checkout으로 실행해
`tests/fixtures/r18_cpu_reference.json` 기준값을 만들었다. 이전 구현을 새 코드에 복사하지 않았다.
fixture는 PyTorch 2.5.1 환경의 작은 2-layer BERT(16 hidden, 4 attention heads) 수치 검증 자료이며,
사전학습 BERT 실험 점수가 아니다. 대조군/19개 값을 바꾼 설정 각각 seed 42·43에서
연속 60 step을 실행해 step 56의 정규화 활성화 경계를 지난다. 4000-step 스케줄을 유지한다.

다음이 모두 bit-identical이다.

- 매 teacher/student forward의 문장 임베딩·로짓과 매 step의 전체 gradient 해시.
- 최종 student·teacher와 covariance EMA 상태. 뷰별 EMA 업데이트 60×3회.
- Torch/Python 난수 상태와 loss 성분·weighted 기여·gradient norm·batch-KL 기록.
- 온도·teacher EMA 스케줄의 전체 4,000개 step. best 동률의 최초 선택과 last 저장도 검증한다.

또한 0 가중치 성분의 gradient 제거, teacher/과거 통계 detach, 특수/패딩 마스킹,
epoch tail 처리, bias/norm weight decay 제외, 정밀한 optimizer group 순서를 확인했다.
STS-B 기하와 centered effective rank, 고정 7-task test split/평균, 현재 checkpoint strict loading을 검증했다.
controller 대역 테스트는 fresh control→유한 탐색→3시드 확인→선택 동결→STS7을 완주하며,
후보가 개선 설정일 때와 기준선일 때를 모두 확인한다. 이 테스트의 점수는 전부 인공 데이터다.

실행한 검증 명령:

```bash
CUDA_VISIBLE_DEVICES='' HF_HUB_OFFLINE=1 HF_DATASETS_OFFLINE=1 \
  UV_CACHE_DIR=/tmp/flowdino-uv-cache MPLCONFIGDIR=/tmp/flowdino-mpl \
  uv run --no-sync python -m pytest -q
uv lock --check --offline
uv run --no-sync python -m src.train --help
uv run --no-sync python scripts/run_coviso_optuna.py --help
uv run --no-sync python scripts/analyze_optuna.py --help
uv run --no-sync python scripts/eval_sts7.py --help
uv run --no-sync python scripts/prepare_data.py --help
bash -n scripts/env.sh
```

추가로 Ruff의 F/I 검사와 format check, `git diff --check`를 수행했다.
기존 환경의 패키지를 설치/제거하지 않았으며 uv.lock만 갱신했다.

## 현재 실행 및 검증 한계

진행 중인 `results/experiments/coviso_joint_optuna_20261028`의 고정 소스 SHA-256 전체를
재확인해 변경 없음을 확인했다. 기존 supervisor도 계속 살아 있다. 기존 실행기가 자동 갱신하는
`docs/experiments/coviso_relax/report.md`는 이번 정리 커밋에서 제외한다.
새 루프를 현재 진행 중인 trial에 섞거나 실험을 다시 샘플링하지 않았다.

GPU 작업은 기존 실험이 계정의 두 슬롯을 사용하므로 추가 실행하지 않았다.
CPU에서의 bit-identical 검증은 전체 크기의 사전학습 BERT/CUDA·TF32 4000-step 재현을 대신하지 않는다.
GPU 성능·최종 STS 점수의 동일성은 아직 검증하지 않았다. 점수를 추정해서 채우지 않는다.
리팩토링 전 소스와는 파일 해시가 다르므로 새 campaign은 원칙적으로 대조군을 다시 학습한다.

별도 확인 사항: 기존 `prepare_data.py`는 ModernBERT와 출력 파일명이 하드코딩되어 있었다.
현재 BERT config에서 백본·출력 이름을 읽도록 연결하고 기존 캐시 덮어쓰기를 차단했다.
학습 데이터 캐시는 재생성하지 않았고, 통계 수식·문장 필터·선택 seed는 유지했다.
학습 알고리즘 버그를 발견해 조용히 수정한 사항은 없다.
