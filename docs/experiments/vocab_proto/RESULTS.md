## 사전 등록 판정

- **P1 성립.** C1 − C0 = +1.67 / +2.08 / +1.96, 평균 +1.90pp(주 지표: raw, dev-best checkpoint).
- **P2 성립.** C1의 H_pt/lnK 최댓값은 0.028–0.032(t13 0.997), batch_KL 중앙값은 17.5–17.6(t13 0.047)이다.
- **P3 "MLM head의 학습된 지식이 핵심".** C3 − C1 = −4.84 / −5.49 / −4.15pp. 같은 단어 공간의 k-means 방향만으로는
  C0보다도 낮다(64.17).
- **P4 기각(고정 좌표계로 충분).** C1 − C2 = +1.37 / −1.45 / −0.36. 동결 head의 best 평균이 오히려 높다.
- **P5 판정불가.** 선택된 C1 설정의 노이즈 범위가 t ∈ [0.25, 0.35]로 좁아, 표본 200개 이상인 t 구간이 하나뿐이다.
  참고로 넓은 노이즈를 쓴 anchor(t 0.47–0.90)에서는 student copy rate가 낮은 t 0.21, 높은 t 0.025였다. 퇴화 징후는 아니었으나 판정 근거로 쓰지 않는다.

## 해석과 반드시 함께 읽을 제약

1. **이득은 학습 초반 checkpoint에 있다.** C1/C2의 dev-best는 step 250–1250이며, last checkpoint에서는 C1 66.74, C2 63.24로
   C0(67.04)보다 낮다. last를 주 지표로 했다면 P1은 성립하지 않는다. C2 dev는 step 250에서 이미 77.0–77.4다.
   즉 사전학습 MLM head를 target으로 쓰면 빠르게 좋아지지만, 학습을 계속하면 test 성능이 깎인다. 이 방법의 현재 형태는
   "짧은 학습 + dev 조기 선택"에서만 C0을 넘는다. 이것은 사전 등록 규칙 안의 결과지만 일반적 우위로 해석하지 않는다.
2. **target은 매우 날카롭다.** 선택된 C1은 τt/τs = 0.18, H_pt/lnK ≈ 0.006–0.03이다. "신호가 사라지는 보수적 해"(ratio > 0.9,
   H/lnK ≥ 0.98)와는 정반대이며, 거의 one-hot에 가까운 단어 분포를 맞추는 방향으로 수렴했다. 후반 하락과의 관계는 미검증이다.
3. **노이즈를 거의 끈 설정이 선택됐다.** C1 t ∈ [0.25, 0.35], C2도 C0보다 약하다. 성능 향상이 "노이즈 + 의미 있는 target"
   상호작용이 아니라 "의미 있는 target" 쪽에서 왔을 가능성이 크다. 같은 탐색 예산이지만 노이즈 축도 같이 바뀌었으므로
   head 하나의 인과 효과로 분리하지 않는다.
4. **C3가 C0보다 낮다.** 무작위 transform과 k-means prototype은 초기 target이 거의 균등(H/lnK 0.987)하며, 단어 공간 방향만으로는
   도움이 되지 않았다. 다만 C3는 C0과 transform 구조·온도 범위가 달라 "C0의 무작위 prototype보다 나쁜 방향"이라고까지 단정하지 않는다.
5. **입력 임베딩.** decoder 저장소 공유는 전 구간 0이다. 입력 임베딩 상대 이동량은 C1 0.045, C2 0.092, C3 0.108로,
   C0 t13의 0.042와 비교된다(모든 조건에서 backbone optimizer가 학습한다).
6. **teacher top-10 단어(C1 seed 42, step 3999)는 의미적으로 타당하다.** "riding on a horse" → riding, horse, horseback, saddle…
   "carrying a boy" → carries, carrying, pregnant, …, pregnancy로, probe에서 본 연상 오류가 학습 후에도 일부 남는다.
